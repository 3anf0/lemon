# SmartCal AI — Clean Setup

## Steps to run:

1. Open this folder in Android Studio (File → Open → select SmartCalendarAI_Clean)
2. Wait for Gradle sync to finish
3. Open local.properties and replace PUT_YOUR_KEY_HERE with your Gemini API key
   - Get free key at: aistudio.google.com → Get API Key → Create API key
4. Connect your phone via USB and allow USB debugging
5. Press the green Play button ▶

## Your local.properties should look like:
sdk.dir=C:\\Users\\Majchrowski\\AppData\\Local\\Android\\Sdk
GEMINI_API_KEY=AIzaSy-YOUR_ACTUAL_KEY
